## Notas de mantenimiento

- **Formato de archivo**: `.safetensors` preferido sobre `.ckpt`/`.pt` por seguridad
- **Metadata**: Cada modelo tiene `.jpeg` (preview) y `.metadata.json` generados por ComfyUI Manager
- **Carpetas vacías** (placeholders para modelos futuros): `animatediff_models/`, `diffusion_models/`, `text_encoders/`, `LLM/`, `audio_encoders/`, `frame_interpolation/`
- **Parcialmente descargado**: `RMBG/rembg/RMBG-1.4.pth` (descarga incompleta, verificar)

## Cómo actualizar este archivo

Al instalar un modelo nuevo, agregar una línea a la tabla correspondiente con:
1. Nombre exacto del archivo
2. Modelo base (SD1.5 / SDXL / Flux / etc.)
3. Fuente (CivitAI / HuggingFace / GitHub)
4. URL de descarga directa o página del modelo
