# Operations Runbook

## Daily Usage Loop
1. Use Architect role to design stage plan.
2. Use Builder role to convert into executable workflow steps.
3. Use Reviewer role for go/no-go decision.

## When Results Are Unstable
1. Reduce graph complexity to a minimal baseline.
2. Re-run with conservative settings.
3. Reintroduce optional modules one by one.

## When Memory Pressure Appears
1. Lower resolution.
2. Remove non-essential heavy modules.
3. Use generate-then-upscale workflow.

## Monthly Maintenance
- Review model inventory alignment.
- Review scenario pass quality.
- Update templates from proven workflows.
- Prune outdated guidance.
