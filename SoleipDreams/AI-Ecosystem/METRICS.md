# Success Metrics

## Core Metrics
1. Time to first workable workflow plan.
2. Rework count before successful execution.
3. Failure rate due to missing dependencies.
4. Estimated VRAM fit accuracy.

## Review Targets
- Weekly trend review for active projects.
- Corrective actions when failure rate rises over baseline.

## Baseline Collection
Track at least 5 representative workflow requests per cycle.
